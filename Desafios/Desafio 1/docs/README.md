# Sistema de Gestão dos Funcionários
Projeto para calcular folha de pagamento simplificada.

## Como rodar?
1. Navegar até a pasta `src`
2. Executar `python main.py`

## Regras de Negócio
- **Freelancer**: 5% de IRRF sobre o total.
- **CLT**: 8% de INSS fixo + 10% de IRRF se o salário for maior que R$ 2000.
- **Estagiário**: Sem descontos aplicados.
